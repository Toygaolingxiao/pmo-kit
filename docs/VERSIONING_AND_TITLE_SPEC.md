# pmo-kit バージョン管理・タイトル表示仕様書

本ドキュメントは `pmo-kit` のタイトル体系、バージョン管理、クレジット表記を定義する。

---

## 1. タイトルおよびクレジット表記設計

### 1.1 pmo-kit の表記
- **プロダクト正式名称**: `pmo-kit`
- **サブタイトル / 役割**: 「PMO プロジェクト推進ダッシュボード / WBS作業ブレークダウン・ガントチャート統合管理」
- **シグネチャ / 署名 (クレジット)**:
  - **`A product by GAO`**
  - トップバーのブランドロゴ近傍およびフッター・プロジェクト情報に、過度な主張を避けつつ洗練されたタイポグラフィ（控えめな文字サイズ、半透明のブランドトーン）で配置。
- **バージョン表記**:
  - トップバー: `Ver 1.0` (バッジ形式)
  - プロジェクト概要ストリップ: `プロジェクト管理台帳 / Ver 1.0`

---

## 2. セマンティック・バージョニング運用規約 (SemVer)

pmo-kit のバージョンは次の規則で上げる。手順の正本は [`docs/01-versioning.md`](./01-versioning.md) を参照する。

```
MAJOR.MINOR.PATCH (例: 1.0.0)
```

1. **MAJOR (主版)**:
   - WBSデータスキーマの大幅改定、破壊的変更、アーキテクチャ刷新。
2. **MINOR (中版)**:
   - 新機能追加（例: カラム幅ドラッグリサイズ、コンテキストメニュー、Outlook連携、Excel双方向同期）。
3. **PATCH (小版)**:
   - バグ修正、UI/UX調整、稲妻線アライメント微調整、日本語文言の修正。

---

## 3. Web UI における表示ガイドライン

1. **ヘッダーエリア**:
   - `pmo-kit` ロゴの右横に `Ver 1.0` バッジを配置。
   - `A product by GAO` をヘッダーの控えめなメタ情報、またはフッターの著作権表示エリアに美しくレイアウト。
2. **プロジェクト計画情報 (Meta Strip)**:
   - プロジェクトコード、ベースライン版数、責任者 (GAO)、基準日を一覧表示。
