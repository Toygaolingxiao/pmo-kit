# 変更履歴 (Changelog)

すべての重要な変更は本ファイルに記録されます。
フォーマットは [Keep a Changelog](https://keepachangelog.com/ja/1.0.0/) に基づき、バージョンは [Semantic Versioning](https://semver.org/lang/ja/) に準拠しています。

---

## [1.1.1] - 2026-10-13

### Changed
- 週次ステータスと Mermaid ガントの見出しを、計画データ自身のプロジェクト名から生成する。
- 公開向けの README を現在の作業台と CLI の範囲に合わせて書き直した。

### Removed
- 特定案件の文面、ローカルパス、テンプレートに残っていた個人名・組織名。

## [1.1.0] - 2026-09-30

### Added
- **課題の有限状態機械**:
  - 未着手、進行中、解決済み、クローズ、取消の合法な遷移だけを許可
  - 担当者へ渡すと未着手に戻り、受け取った担当者が受領して進行中にする
  - 起票者だけが期日を直接変更でき、それ以外は延伸申請と承認が必要
  - 今週末までの課題で 7 日以上更新がないものは要更新キューへ
  - `@名前` のメンションはリアクションまたは返信まで残る
  - 玉持ち不明は起票者を一時担当にし、木曜の横断定例キューへ
  - プロジェクトの PMO（meta.pm）への改善提起
  - 操作者はローカルに記憶し、課題データとは分ける
- **WBS 状態の遷移制限**:
  - クイックメニューとコンテキストメニューは現在の状態から進める項目だけを表示
  - 進捗率 0% から 100% への直接変更を拒否

## [1.0.0] - 2026-09-14

### Added
- **モダン PMO ワークベンチ (Web UI)**:
  - WBS 階層管理テーブル（複数選択、ドラッグ幅調整、インデント/反インデント、複製、削除）
  - デュアルガントチャート表示（計画バー・実績バー・マイルストーン・依存関係矢印）
  - 業界標準の**稲妻線（進捗折線 / Progress Line）**:
    - 状態日（基準日）による垂直基準線
    - 進行中タスクの動的左右オフセット（遅延は左へ凹み、進捗は右へ突起）
    - 完了タスクの基準日垂直固定化（視覚ノイズ抑制）
    - 未来未着手タスクの基準日アラインメント（無駄な右突起を防止）
  - 期間ナビゲーション機能（「−1ヶ月」「−1週」「基準日」「+1週」「+1ヶ月」）
  - WBS 行コンテキストメニュー（右クリックで子タスク追加、下へ挿入、進捗率即座設定、状態変更、複製、削除）
  - ステータスバッジのワンクリッククイック変更ポップアップ
  - 担当者・作業名のインライン編集（ダブルクリック/クリック即編集）
  - 祝日カレンダー管理ダイアログ（日本の祝日一括自動判定）
  - 定例会議（Outlook / Web Composer 連携）ダイアログ
  - プロジェクト概要（Overview）ダッシュボード（加重進捗率、未完了マイルストーン、RAIDメトリクス、注視事項）
  - RAID（リスク・課題・前提・依存関係）カード管理ビュー
  - 変更履歴（ChangeLog）自動記録・閲覧機能
  - Undo / Redo（元に戻す・やり直す）スタック
  - JSON 計画データの入出力（エクスポート・インポート）
- **モジュール分割・アーキテクチャ刷新**:
  - `web/js/utils.js`: 日付計算・サニタイズ・共通定数
  - `web/js/holidays.js`: 日本の祝日（振替休日・ハッピーマンデー対応）計算エンジン
  - `web/js/gantt-calc.js`: ガント要約・遅延判定・稲妻線座標アルゴリズム
  - `web/js/components/wbs-table.js`: 列リサイズ・SVG 稲妻線描画
  - `web/js/components/dialogs.js`: タスク編集・定例会議・Outlook 連携ダイアログ
  - `web/js/components/history.js`: 変更履歴・RAID カード・サンプル階層ツリー描画
  - `web/repository.js`: LocalStorage 永続化およびシードデータ読み込み
  - `server.js`: Node.js 組み込み静的配信サーバー
- **Excel 相互変換エンジン**:
  - `src/excel.ts`: 相互双方向変換（Excel ⇄ `project-plan.json`）
- **CLI 静的ビルド・レポート生成**:
  - `src/render.ts`: HTML / CSV / Mermaid / 週次ステータス Markdown 生成
- **バージョン管理体系**:
  - `VERSION` ファイル正本管理
  - `docs/01-versioning.md`
  - `docs/10-changelog.md`
- **ブランディング**:
  - `A TAKAE PRODUCTION` クレジットおよびデザインシステム統一

### Fixed
- プロジェクト概要（Overview）描画時の DOM 要素参照 null エラーを完全解消し、安全な null ガードを実装。
- コンテキストメニューおよび状態変更ポップアップが画面右端・下端ではみ出す問題を自動反転計算ロジックにより解消。
- タスク進捗状態（未着手・進行中・完了・遅延）の配色コントラストおよび視認性を大幅向上。
